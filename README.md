# dep-second-opinion-dogfood

Minimal **public** dogfood host for [`lory69060/dep-second-opinion`](https://github.com/lory69060/dep-second-opinion).

- Dependabot (npm, weekly) opens upgrade PRs
- Path A Action pins `uses: lory69060/dep-second-opinion@v0.2.0` and posts a **comment-only** second opinion
- Not a production app — safe to leave open for demos

Install guide: [docs/install.md](https://github.com/lory69060/dep-second-opinion/blob/main/docs/install.md)

```yaml
- uses: lory69060/dep-second-opinion@v0.2.0
```
